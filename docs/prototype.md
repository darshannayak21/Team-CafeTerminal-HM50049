# Round 1 Prototype

## Scope

The Round-1 prototype is planned to demonstrate a functional vertical slice connecting:

Environmental observations
→ Hazard assessment
→ Settlement impact
→ Road accessibility/risk
→ Response prioritization
→ Responder-facing visualization

## Current Status

Repository initialized. Application functionality has not yet been implemented.

## Planned Round-1 Components

- Pune District geographic scope
- Flood as the primary hazard
- Rainfall/environmental input
- Terrain-based susceptibility
- Flood-risk visualization
- Settlement impact
- Road-risk/accessibility layer
- Response priority
- Responder dashboard

Features will be marked as implemented only after they are actually developed and tested.
